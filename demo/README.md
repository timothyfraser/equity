# demo: early prototypes (2025)

These scripts and sample files are the team's first experiments with the equity index, kept for the record. **The
paper does not use them**, and they are not maintained: some read files or packages that are no longer here.

For the analysis in the paper, start at the [root README](../README.md). The index the paper uses is `get_index()` in
[`../index/functions.R`](../index/functions.R).
